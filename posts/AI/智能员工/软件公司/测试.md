# 测试（软件公司）

> 状态：⬜ 待写（骨架已初始化）
> 上游：程序员
> 下游：产品经理 / 设计师 / 程序员
> 核心交付：用例、缺陷单、测试报告
> 目标成熟度：L3

## 1. 角色边界

负责：
- 按提测单设计用例、执行测试、管理缺陷。
- 给出覆盖、通过率、遗留风险与结论。
- 守住发布前的质量门禁。

不负责：
- 判断需求价值。
- 替程序员修业务代码（可提修复建议）。
- 只贴数据不给结论。

## 2. 日常动作

| 频次 | 动作 | 产出 |
|------|------|------|
| 每提测 | 用例设计与评审 | 用例集 |
| 每提测 | 执行与缺陷跟踪 | 缺陷单 |
| 每提测 | 回归与报告 | 测试报告 |
| 发布前 | 质量门禁 | 放行 / 拦截建议 |

## 4. 交接物模板

| 字段 | 说明 |
|------|------|
| 覆盖范围 | 需求、模块、接口 |
